# Wireframe HRIS IBB

Prototype klik (statis) dari Blueprint HRIS IBB v1.2.0. Buka `index.html`.

Cara publish di GitHub Pages: upload semua file ke repo (disarankan **private**), lalu Settings > Pages > Source: branch `main`, folder `/ (root)`.

Catatan: navigasi sidebar, tombol Tambah / Buka / Batal antar layar bisa diklik. Interaksi di dalam layar (toggle, tambah tahap approval, pilih mode izin) tidak aktif di versi statis ini; versi lengkap ada di canvas Wireframe HRIS IBB.
